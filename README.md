# 日報・給与明細（サンプル）

従業員がスマホで入れた日報から、月ごとの給与明細を作り、確定・PDF配布までを Web で完結させるツールのサンプルです。
実際に運用しているツールから、依頼者に関わる情報を取り除いて公開しています。

もともとは「日報を LINE で送る → 事務員が Excel に写す → 明細を作る → PDF を LINE で送る」という手作業でした。これを Web アプリ1つに置き換えています。

## できること

### 従業員（スマホで操作）

- 日報を入力する（日付・現場名・作業時間・残業時間だけ。単価は入れない）
- 自分の日報の一覧を見て、直す
- 確定した給与明細を見る、PDF でダウンロードする

### 管理者（社長・事務員）

- 全員の日報を確かめる、直す、足す
- 従業員ごとの時給・残業の倍率・毎月の固定控除を設定する
- 「この月の明細を生成」で、日報から給与明細を自動で作る（元請けごとの手直しもできる）
- 明細を承認して確定する（確定すると従業員が見られるようになる）
- 前払いの台帳、振込の確認、元請けへの請求書の作成・メール送信

## 使っている技術

| 役割 | 技術 |
|---|---|
| 画面・API | Next.js（App Router）、TypeScript、Tailwind CSS |
| データベース | Prisma（手元は SQLite、本番は PostgreSQL） |
| ログイン | iron-session |
| PDF | @react-pdf/renderer |
| メール送信 | Nodemailer（Gmail） |

## 動かし方

1. パッケージを入れる

   ```bash
   npm install
   ```

2. `.env.example` をコピーして `.env` を作り、`SESSION_SECRET` に32文字以上のランダムな文字列を入れる

3. データベースを作って、作り物のデータを入れる

   ```bash
   npx prisma migrate dev
   npm run db:seed
   ```

4. 起動する

   ```bash
   npm run dev
   ```

   http://localhost:3000 を開くと、ログイン画面が表示されます。

## 毎月の流れ

1. 従業員が日報を入力する
2. 事務員が日報を確かめる
3. 「承認・確定」で、その月の明細を日報から生成する
4. 必要なら、元請けからの情報に合わせて明細を手直しする
5. 承認して確定する
6. 従業員が Web で明細を見て、PDF を受け取る

## 注意

- このリポジトリには、本物の鍵・従業員や給与のデータ・依頼者の情報は入っていません。会社名・現場名・人の名前はすべて作り物です。
- `.env` は公開しないでください（`.gitignore` で除外しています）。
